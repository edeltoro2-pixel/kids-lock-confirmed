# Learning Break: email confirmed

The page parents see after tapping the confirmation link in the Learning Break sign-up
email. It says the account is confirmed (or that an old link no longer works) and points
them back to the app.

Supabase adds sign-in tokens to the address when it sends people here; the page removes
them straight away and needs no other data. No tracking, cookies or analytics.
